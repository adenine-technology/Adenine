The Platform

Four Modules. One Cryptographic Root.

AES-256-GCM / Argon2id
01 / VAULT

Credential Manager

Master passwords pass through client Argon2id key derivation. Remote servers store only blind encrypted blobs.

02 / NOTES

Encrypted Notes

Local-first markdown notes. Full-text search runs strictly in-memory through local client indexing.

03 / CALENDAR

Zero-Leak Scheduling

Event timestamps and metadata are envelope-encrypted before storage to prevent temporal profiling.

04 / TASKS

State Checklists

Peer-to-peer task tracking with encrypted conflict-free replicated data types (CRDTs) over WebRTC.
